# 🧪 Super Chemistry Bot (MVP)

Боти телеграм барои омӯзиши химия: ҷадвали даврии кӯҳна (8 гурӯҳ), тарзи ҳалли
масъалаҳо, ҳисобкунаки массаи молярӣ, AI муаллим (Groq) ва пешрафти истифодабаранда.

## Функсияҳое, ки дар ин MVP ҳастанд

- 📊 **Ҷадвали даврии кӯҳна** — намуди кӯҳна бо 8 гурӯҳ (IA-VIIIA, IB-VIIIB), на 18-гурӯҳаи муосир.
- 📐 **Тарзи ҳалли масъалаҳо** — 5 алгоритми асосӣ (массаи молярӣ, моль, консентратсия, стехиометрия, ҳаҷми газ) бо мисоли ҳалшуда + тугмаи "Мисоли нави AI".
- 🧮 **Ҳисобкунаки массаи молярӣ** — формуларо нависед (масалан `Al2(SO4)3`), бот массаи молярии онро ҳисоб мекунад.
- 🤖 **AI муаллим** — саволи озод дар бораи химия, ҳалли онро Groq (llama-3.3-70b) медиҳад.
- 📈 **Пешрафти ман** — SQLite нигоҳ медорад, ки чанд бор шумо аз ҳар функсия истифода бурдед.

## Функсияҳое, ки ҲАНӯЗ дохил НАШУДААНД (қадами навбатӣ)

Тибқи нақшаи аслӣ (санҷиш/квиз бо холбандӣ, баланс кардани муодилаҳои реаксия,
омодагӣ ба олимпиада) — инҳо қасдан дохил нашудаанд, то лоиҳа кӯчак ва
тестшаванда монад. Пас аз санҷидани MVP, модул ба модул илова кунед.

## Сохти лоиҳа

```
chembot/
├── bot.py            # Ҳалқаи асосии бот (long polling, faqat requests)
├── elements_data.py  # Маълумоти ҷадвали даврии кӯҳна
├── methods_data.py   # Алгоритмҳои ҳалли масъала
├── calculators.py    # Таҳлили формула + ҳисоби массаи молярӣ
├── groq_client.py    # Муштарии Groq API (бо retry)
├── db.py             # SQLite — корбарон ва пешрафт
├── requirements.txt
├── Procfile
└── .env.example
```

## Насб дар Termux (озмоиш дар мошин)

```bash
pkg install python
pip install -r requirements.txt
cp .env.example .env
# .env-ро кушоед ва TELEGRAM_BOT_TOKEN, GROQ_API_KEY-ро гузоред
export $(cat .env | xargs)
python bot.py
```

Токени бот аз [@BotFather](https://t.me/BotFather) ва калиди Groq аз
[console.groq.com](https://console.groq.com) гирифта мешавад.

## Деплой дар Railway

1. Лоиҳаро ба GitHub repo пуш кунед (ин файлҳоро айнан).
2. Дар Railway → New Project → Deploy from GitHub repo.
3. Дар Variables ду калидро илова кунед: `TELEGRAM_BOT_TOKEN`, `GROQ_API_KEY`.
4. Railway худ `Procfile`-ро мебинад ва `worker: python bot.py`-ро иҷро мекунад.
5. Баррасӣ кунед, ки Deploy Logs хатогӣ надошта бошад — паём "Super Chemistry Bot оғоз шуд..." бояд намоён шавад.

## Нуктаҳои техникӣ

- Танҳо `requests` истифода шудааст (бе aiogram/python-telegram-bot), бинобар
  мушкилоти маъмулии компиляцияи Rust дар Termux/Android.
- Ҳолати гуфтугӯ (масалан "мунтазири формула") дар хотир (`USER_STATE` dict)
  нигоҳ дошта мешавад — барои як instance кофист.
- SQLite (`chembot.db`) дар ҳамон папка сохта мешавад — дар Railway бо har deploy
  тоза мешавад (эфемерӣ).
