# TAJWAY CARGO BOT

Боти Telegram барои идоракунии трек-кодҳо, доставка ва муоширати корбарон бо admin.

## Функсияҳо

- Регистратсияи корбар (рақами телефон + ном)
- Ҷустуҷӯи трек-код (статуси худкор: агар аз лаҳзаи иловашуданаш {AUTO_STATUS_DAYS} рӯз гузашта бошад → "Дар роҳ")
- Илова кардани якчанд трек-код якбора (admin)
- Таҳрир/нест кардани трек
- Борҳои ман (таърихи ҷустуҷӯи корбар)
- Борҳои манъшуда (қобили таҳрир аз admin)
- Адреси склад дар Чин (қобили таҳрир аз admin)
- Калькулятори нарх (кг × нарх, қобили таҳрир аз admin)
- Дархости доставка + пардохт + тасдиқ/радди admin
- Тамос бо admin (чат дуҷониба дар дохили бот)
- Паёми умумӣ ба ҳамаи корбарон (broadcast)
- 3 забон: тоҷикӣ, русӣ, англисӣ
- Якчанд admin якбора (ADMIN_IDS)

## Насб дар Railway

1. Лоиҳаро ба GitHub push кунед.
2. Дар Railway → New Project → Deploy from GitHub repo.
3. Дар қисми **Variables** инҳоро илова кунед:

| Калид | Тавзеҳ | Мисол |
|---|---|---|
| `BOT_TOKEN` | Токени бот аз @BotFather | `123456:AA...` |
| `ADMIN_IDS` | ID-ҳои admin (бо вергул ҷудо) | `111111111,222222222` |
| `PAYMENT_NUMBER` | Рақами пардохт | `989091111` |
| `ADMIN_USERNAME` | Юзернейми admin | `@Tajwaycargo` |
| `PRICE_PER_KG` | Нархи 1 кг | `25` |
| `DEFAULT_ARRIVAL_CITY` | Шаҳри пешфарз | `Истаравшан` |
| `DEFAULT_ESTIMATED_DAYS` | Мӯҳлати пешфарз | `20-25 рӯз` |
| `AUTO_STATUS_DAYS` | Баъд аз чанд рӯз "дар роҳ" гӯяд | `10` |

4. Railway худкор Procfile-ро мехонад (`worker: python bot.py`).
5. Deploy кунед — бот кор мекунад.

### Гирифтани ID-и admin
Дар Telegram ба **@userinfobot** равед ва "Start" пахш кунед — вай ID-и шуморо мефиристад.

## Формати иловаи бисёртрека (admin)

Дар Admin Panel → "➕ Илова кардани трек(ҳо)" ин формат кор мекунад (ҳар хат = як трек):

```
KH22FF99
GG22KK|Usmonov|20-25 рӯз|Истаравшан
JJ32SD
```

Агар танҳо код нависед, ном/рӯз/шаҳр аз танзимоти пешфарз гирифта мешавад.

## Эзоҳ

- Пойгоҳи додаҳо SQLite аст (`cargo_bot.db`), дар доираи контейнери Railway захира мешавад.
- Ҳолати "чат бо admin" (кӣ ба кӣ ҷавоб медиҳад) дар хотира нигоҳ дошта мешавад — агар бот аз нав оғоз шавад (restart), ин ҳолат тоза мешавад, вале худи паёмҳо гум намешаванд.
