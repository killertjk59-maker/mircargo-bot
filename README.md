# Tezcargo — боти Telegram

Бот барои трек-кодҳо, доставка, омори борҳо ва ҳисоби қарзу пардохти муштариён.
Забонҳои менюи муштарӣ: тоҷикӣ, русӣ ва англисӣ. Панели админ ба тоҷикӣ аст.

## Имкониятҳо

- Сабти ном бо телефон ва ном; ҷустуҷӯи трек; «Борҳои ман».
- Иловаи як ё якчанд трек, таҳрири маълумот, бойгонии трек.
- Мақомҳо: **дар анбори Чин → дар роҳ → расид → ба муштарӣ дода шуд**.
- **Instagram:** тугма дар меню, ки пайванди кушодани Instagram-ро нишон медиҳад.
  Пайвандро админ метавонад баъдтар гузорад ё иваз кунад.
- **Омори админ:** борҳои умумӣ, фаъолу бойгонӣ, расидаву дода шуда,
  шумораи муштариёни гуногуни боргирифта, корбарон, ҷустуҷӯҳо ва доставка.
- **Ҳисоб барои ҳар муштарӣ, на барои ҳар трек:** сабти қарз ва пардохт,
  тасдиқи амалиёт, бақияи худкор, аванс ва таърихи 10 амалиёти охирин.
- **Қарздорон:** ном, телефон, қарз, пардохт ва бақия; саҳифабандӣ ва
  зеркашии **рӯйхати пурра дар CSV** барои админ.
- Борҳои манъшуда, адреси анбор, калькулятор, дархости доставка,
  тасдиқи пардохти доставка, чат бо админ ва паём ба ҳама.
- Пеш аз дархости доставка трек бояд дар система бошад; дархости фаъол/тасдиқшудаи такрорӣ
  барои ҳамон корбару трек баста мешавад. Ҷустуҷӯи трек соҳиби бор буданро исбот намекунад —
  админ бояд шахсияти дархосткунанда ва пардохтро худаш санҷад.
- Якчанд админ тавассути `ADMIN_IDS`.

Ҳисобҳо, қарздорон ва омор **танҳо дар чати хусусии админ** дастрасанд.
Ҷустуҷӯи трек маънои соҳиби бор ё гирандаи бор буданро надорад.

## Насб дар Railway

1. Репозиторияро ба Railway пайваст кунед: **New Project → Deploy from GitHub repo**.
2. **Volume** созед ва онро ба `/data` пайваст кунед. Бе volume база ҳангоми
   иваз шудани контейнер ё deploy метавонад гум шавад.
3. Дар **Variables** танзим кунед:

| Калид | Тавзеҳ | Мисол |
|---|---|---|
| `BOT_TOKEN` | Токени воқеии бот аз @BotFather | Дар Variables гузоред, на дар Git |
| `ADMIN_IDS` | Telegram ID-и админҳо, бо вергул ҷудо | `111111111,222222222` |
| `ADMIN_USERNAME` | Юзернейми воқеии админ; ихтиёрӣ | `@your_admin` |
| `INSTAGRAM_URL` | Ихтиёрӣ; метавонед баъдтар аз панели админ гузоред | `https://www.instagram.com/your_page/` |
| `DB_PATH` | База дар volume-и доимӣ | `/data/cargo_bot.db` |
| `PAYMENT_NUMBER` | Рақами пардохт | `989091111` |
| `PRICE_PER_KG` | Нархи 1 кг, сомонӣ | `25` |
| `DEFAULT_ARRIVAL_CITY` | Шаҳри пешфарз | `Истаравшан` |
| `DEFAULT_ESTIMATED_DAYS` | Мӯҳлати пешфарз | `20-25 рӯз` |
| `AUTO_STATUS_DAYS` | Баъд аз чанд рӯз мақоми худкор «Дар роҳ» шавад | `10` |

4. Railway `Procfile`-ро мехонад: `worker: python bot.py`.
5. Deploy кунед. Дар Telegram `/start` ва барои админ `/admin`-ро истифода баред.

Барои гирифтани Telegram ID ба **@userinfobot** равед.
Токен ва рақамҳои воқеии админро дар чат ё файлҳои Git нафиристед.

### Номи бот дар Telegram

Матнҳо ва номи бот **Tezcargo** мебошанд. Ҳангоми оғоз бот бо `setMyName`
номи намоиширо ба Tezcargo иваз мекунад. Агар Telegram ин дархостро қабул
накунад, дар @BotFather фармони `/setname`-ро истифода баред.
**@username-и бот тағйир намеёбад**; онро танҳо соҳиби бот тавассути @BotFather
иваз карда метавонад, агар номи дилхоҳ озод бошад.

## Instagram

**Admin Panel → 📷 Пайванди Instagram**:

```text
https://www.instagram.com/your_page/
```

Ё `@your_page` нависед. Танҳо пайвандҳои HTTPS-и домени Instagram қабул мешаванд.
`/clear` пайвандро хориҷ мекунад; `/cancel` таҳрирро бекор мекунад.
Пайванди гузоштаи админ нисбат ба `INSTAGRAM_URL` афзалият дорад.
То гузоштани пайванд бот «ҳоло гузошта нашудааст» мегӯяд — саҳифаи сохта
ё пайванди тахминӣ истифода намешавад.

## Борҳо ва ҳисоб кардани гирифташудаҳо

### Иловаи трек

**Admin Panel → ➕ Илова кардани трек(ҳо)**, ҳар хат як трек:

```text
KH22FF99
GG22KK|Али Раҳимов|20-25 рӯз|Истаравшан
JJ32SD
```

Трек-код: 1–40 ҳарфу рақами лотинӣ; `-`, `_`, `.`, `/` низ иҷозат доранд.
Ном, рӯз ва шаҳр ихтиёрӣ мебошанд. Иловаи такрорӣ танҳо маълумотро нав мекунад:
расидан, гирифтани бор ва санаҳои пештара аз нав ҳисоб ё тоза намешаванд.

### Бор расид

**Admin Panel → 📦 Борҳо расиданд**, трек-кодҳоро фиристед, ҳар хат як код.
Расидан танҳо бо сабти воқеии админ ҳисоб мешавад; гузаштани рӯзҳо танҳо
мақоми «Дар роҳ»-ро тағйир медиҳад, на расидан ё гирифтанро.
Мақомро инчунин аз **Таҳрири трек → Мақом** интихоб кардан мумкин аст.

### Бор ба муштарӣ дода шуд

1. **Admin Panel → ✅ Додани бор**.
2. Трек-коди бори расидаро нависед.
3. Муштарии воқеии гирандаро интихоб кунед ё муштарии нав созед.
4. Танҳо баъди додани бор тугмаи **«Бор дода шуд»**-ро тасдиқ кунед.

Шумораи борҳои гирифташуда аз трекҳои додашуда ҳисоб мешавад. Шумораи
муштариёни гуногун аз ҳисобҳои интихобшуда ҳисоб мешавад: **ҳар телефон як
муштарӣ**. Агар як муштарӣ 3 бор гирад, омор 3 бор ва 1 муштариро нишон медиҳад.
Пахши такрории тасдиқ як борро ду маротиба ҳисоб намекунад.
Қарзи муштарӣ ҳангоми додани бор нишон дода мешавад, вале гирифтани бор
худ аз худ қарзро кам намекунад — пардохтро алоҳида сабт кунед.

### Бойгонӣ

«Бойгонии трек» онро аз ҷустуҷӯ ва рӯйхати фаъол пинҳон мекунад, вале таърихи
расидан/гирифтан дар омори умумӣ нигоҳ дошта мешавад. Иловаи ҳамон код онро
аз бойгонӣ бармегардонад, бе сохтани бори дуюм. Борҳои аллакай додашударо
бо иваз кардани мақом аз нав «дар роҳ» ё «расид» кардан мумкин нест.

## Қарз ва пардохт — алоҳида барои ҳар муштарӣ

1. **Admin Panel → 💳 Ҳисоби муштариён → ➕ Муштарии нав**:

   ```text
   Али Раҳимов | +992901234567
   ```

   Рақами маҳаллии тоҷикӣ, масалан `901234567`, ба `+992901234567` табдил мешавад.
   Ҳисоби дуюм бо ҳамон телефон қабул намешавад. Барои муштарӣ Telegram доштан
   шарт нест; ҷустуҷӯкунандагон худкор ба ҳисобдорӣ дохил намешаванд.

2. Дар ҳисоби муштарӣ **«Сабти қарз»** ё **«Сабти пардохт»**-ро интихоб кунед:

   ```text
   125.50 | Қарзи аввалия ё сабаби амалиёт
   ```

   Шарҳ ихтиёрӣ аст (то 500 аломат). Маблағ мусбат, то 2 рақам баъди нуқта;
   `125,50` низ қабул мешавад. **Пеш аз сабт тасдиқ мепурсад**.

3. Бот ҳисоб мекунад:

   ```text
   Бақия = ҳамаи қарзҳои сабтшуда − ҳамаи пардохтҳои сабтшуда
   ```

   Бақияи мусбат — қарз; сифр — ҳисоб пӯшида; бақияи манфӣ — аванс.
   Аванси як муштарӣ қарзи муштарии дигарро кам намекунад.
   Маблағҳо дар база бо **дирами бутун**, на `float`, захира мешаванд.

4. **📋 Қарздорон** ё `/debtors` — танҳо муштариёне, ки бақияи мусбат доранд.
   Рӯйхат саҳифабандӣ мешавад; CSV ҳамаи қарздоронро мегирад, на танҳо саҳифаи ҷорӣ.
   Ном, телефон ва дигар маълумоти шахсии CSV-ро бехатар нигоҳ доред.

Амалиётҳо бо админ, сана, маблағ ва шарҳ нигоҳ дошта мешаванд. Пахши такрории
ҳамон тасдиқ амалиёти молиявии дуюм намесозад. Барои ислоҳи сабти нодуруст
амалиёти муқобилро бо шарҳи равшан сабт кунед (масалан, пардохт барои бекор
кардани қарзи нодуруст), то таърих гум нашавад.

**Муҳим:** «Ман пардохт кардам» ва тасдиқи пардохти доставка ба ин ҳисобдорӣ
худкор маблағ илова намекунанд: дархости доставка нархи муайян надорад ва ин
далели гирифтани бор нест. Танҳо админ метавонад пардохти воқеиро сабт кунад.

## Фармонҳои админ

- `/admin` — панели админ.
- `/stats` — омори умумӣ аз ҳамаи сабтҳои нигоҳдошташуда.
- `/customers` — ҳисобҳои муштариён.
- `/debtors` — рӯйхати қарздорон.
- `/ban USER_ID` ва `/unban USER_ID` — маҳдуд ё барқарор кардани дастрасии корбар. Админҳо манъ карда намешаванд.
- `/cancel` — бекор кардани амалиёти ҷорӣ.

## Навсозии базаи пешина

- **Пеш аз deploy нусхаи эҳтиётии база созед.** Ҳангоми backup ботро қатъ кунед
  ё SQLite backup API-ро истифода баред, то нусха яклухт бошад.
- `init_db()` ҷадвалу сутунҳои навро бе нест кардани маълумоти пешина илова мекунад.
- Корбарон, трекҳо, доставка ва танзимоти шахсӣ нигоҳ дошта мешаванд. Танҳо
  адресҳои пешфарзи тағйирнаёфтаи бренди кӯҳна ба Tezcargo иваз мешаванд.
- Мақомҳои маъмули пешина шинохта мешаванд, вале санаи расидан/гирифтан,
  гирандаи таърихӣ ва маблағи қарз **тахмин карда намешаванд**. Борҳои кӯҳнаи
  гирифташуда бе муштарии маълум дар омор алоҳида огоҳӣ доранд.
- Маълумоти қаблан аз база воқеан нестшуда барқарор ё аз нав ҳисоб карда намешавад.
- Қарзҳои пешинаро барои ҳар муштарӣ ҳамчун қарзи аввалия сабт кунед.
- Қарзҳо, омори тасдиқшуда, ҳолатҳои муколама ва харитаи ҷавобҳои админ дар SQLite нигоҳ дошта мешаванд.
  Ҳангоми навсозӣ ҷадвалҳои нави муколама худкор илова мешаванд; маълумоти пешина нест карда намешавад.

## Оғози маҳаллӣ ва санҷиш

Python 3.10+:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Барои оғоз `BOT_TOKEN` ва `ADMIN_IDS`-ро дар муҳити shell гузоред ва
`python bot.py` иҷро кунед. `.env.example` намунаи танзимот аст; бот `.env`-ро
худкор намехонад. Санҷишҳо базаи муваққатӣ ва Telegram API-и mock-ро истифода
мебаранд; токен ё паём ба Telegram лозим нест.
